# AI Agent Activity Interface (React)

A React web interface to manage AI agent activities:
- add activities with descriptions
- turn each activity ON/OFF
- view live state badges
- inspect per-activity timestamped history

## Quick start

```bash
npm install
npm run dev
```

Then open the local Vite URL (typically `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```
